Build me an animated 3D personal portfolio website using Next.js 16 (App Router) with the following specifications:
Tech Stack:
* Next.js 16 (App Router, Server Components where appropriate)
* TypeScript
* Tailwind CSS for styling
* React Three Fiber + @react-three/drei for 3D scenes (using procedural geometries — no external .glb/.gltf models)
* Framer Motion for UI/page animations
* GSAP + ScrollTrigger for scroll-based sequencing
Pages/Sections:
1. Hero Section – Full-screen R3F scene: a distorted/animated icosahedron or torus knot using MeshDistortMaterial or custom shader (via shaderMaterial), reacting to mouse movement (parallax via useFrame + pointer lerp). Name, title, tagline with staggered text reveal.
2. About Me – Bio with a floating procedural shape (e.g., low-poly blob) using useFrame for idle rotation/float.

5. Experience/Timeline – Vertical timeline, scroll-triggered reveal using GSAP ScrollTrigger + Framer Motion combo.
6. Contact – Form with animated focus states, ambient procedural particle background (InstancedMesh for performance).

* Procedural geometries only: Icosahedron, TorusKnot, Sphere, custom BufferGeometry particle fields — no asset loading pipeline needed.
* Custom shader material for the hero object (vertex distortion + fresnel/rim lighting) if feasible — otherwise MeshDistortMaterial/MeshWobbleMaterial from drei.
* Particle system using InstancedMesh or Points with a custom shader for a subtle ambient background across sections.
* Camera/pointer-based parallax in the Canvas using useThree + useFrame.
* GSAP ScrollTrigger to sync 3D scene transforms (rotation/scale/position) with scroll progress.
* Smooth route/page transitions via Framer Motion AnimatePresence.
Architecture (advanced-level expectations):
* Modular Canvas setup: separate Scene, Lights, CameraRig, and individual mesh components.
* Custom hooks: useMousePosition, useScrollProgress, useResponsiveCanvas.

* Performance: frustum culling awareness, dpr capping ([1, 2]), disable shadows unless essential, dispose geometries/materials on unmount.
* Respect prefers-reduced-motion — provide a static/lightweight fallback for accessibility.
